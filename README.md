# Supply Chain Management Dashboard

## Project Overview
This Power BI dashboard analyzes supply chain operations, inventory levels, procurement performance, logistics efficiency, and supplier performance to support data-driven decision-making and operational optimization.

## Tools Used
- Power BI
- Excel

## Features
- Executive Supply Chain Overview
- Inventory Management and optimization
- Demand vs Supply Analysis
- Supplier Performance
- Lead Time and Delivery Delay
- Service Level and SLA Compliance
- Procurement Efficiency
- 

## Key Insights
- Monitored inventory levels to identify stock shortages and overstock situations.
- Evaluated supplier performance based on delivery time, quality, and reliability metrics.
- Analyzed procurement costs to identify cost-saving opportunities.
- Tracked order fulfillment rates and delivery performance across regions.
- Visualized demand and supply trends to improve inventory planning and forecasting.
